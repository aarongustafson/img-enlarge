<img-enlarge>

Enlarge an image without changing its link. Read the README for installation and API details.

Read the README View on GitHub esm.sh example unpkg example

One-off image enlargement

Wrap an image in <img-enlarge>. An Enlarge button appears, but only when there’s room to show the image larger. Use the button to open it; press Escape or the Close button to return focus to the Enlarge button. Without JavaScript the image still renders normally.

The component treats img and picture elements as equally valid images to enlarge. More on that shortly. 

<script type="module" src="../define.js"></script>

<img-enlarge>
  <img src="./mountains.svg"
    alt="A trail between two green mountains beneath a golden sun.">
</img-enlarge>

Force enlargement

Add the force attribute to bypass the space checker and always show the Enlarge button. 


<img-enlarge force>
  <img src="./mountains.svg"
    alt="A trail between two green mountains beneath a golden sun.">
</img-enlarge>

Alternate enlarged versions

By default, the enlargement uses the original image. You can link to a larger file, let the browser choose from responsive images, or supply a separate enlargement.

Use an existing image link

Link the image to a larger file. The Enlarge button uses that file, while clicking the thumbnail still follows the link. 

<img-enlarge>
  <a href="./mountains-large.svg">
    <img src="./mountains.svg" alt="A trail between green mountains.">
  </a>
</img-enlarge>

Let the browser choose the larger image

Keep srcset and sizes on the image and let the browser choose a larger candidate for the viewer. 

<img-enlarge class="responsive-thumbnail">
  <img src="./mountains.svg?responsive=small"
    srcset="./mountains.svg?responsive=small 800w,
      ./mountains-large.svg?responsive=large 1200w"
    sizes="192px"
    width="800" height="400"
    alt="A trail between green mountains.">
</img-enlarge>

<style>
.responsive-thumbnail > img {
  inline-size: min(100%, 12rem);
}
</style>

Use the <picture> element

A picture can use different images at different window widths. Resize the window to try this example. The component will identify which <source> the browser chose and uses its image sizes. 

<img-enlarge class="responsive-thumbnail">
  <picture>
    <source media="(min-width: 40rem)"
      srcset="./mountains.svg?picture=small 800w,
        ./mountains-large.svg?picture=large 1200w" sizes="192px">
    <img src="./mountains.svg" alt="A trail between green mountains.">
  </picture>
</img-enlarge>

Enlarge a specific image

Set src on the component when you want a different enlarged image without adding a link. It takes priority over the image’s link and responsive sources. 

<img-enlarge src="./mountains-large.svg">
  <img src="./mountains.svg" alt="A trail between green mountains.">
</img-enlarge>

Declare several enlargement options

Use srcset on the component to give the viewer its own choice of image sizes. The thumbnail keeps its separate srcset and sizes. 

<img-enlarge src="./mountains-large.svg"
  srcset="./mountains.svg?viewer=small 800w,
    ./mountains-large.svg?viewer=large 1200w">
  <img src="./mountains.svg?thumbnail=small"
    srcset="./mountains.svg?thumbnail=small 800w"
    sizes="192px" alt="A trail between green mountains.">
</img-enlarge>

See the README’s image-source guide for source priorities and less common configurations.

Other attributes

Captions

Put the image in a figure with a figcaption and the enlargement will use that caption. Set caption on the component to use different text in the viewer. The original caption stays in place; an empty caption="" leaves the viewer caption out. 

<img-enlarge caption="An afternoon on the mountain trail.">
  <figure>
    <img src="./mountains.svg" alt="A trail between green mountains.">
    <figcaption>A view from the trail.</figcaption>
  </figure>
</img-enlarge>

Rewrite or translate the labels

The default labels may not work for your application. You can rewrite the button text and messages using the associated *-label attribute on the component for a one-off change, or use a JSON configuration for shared labels.

The default Enlarge button label includes the image’s accessible name. Include {name} in your open-label template to keep that name in a rewritten or translated label. Leave it out for a fixed label, as in the first example.

Rewrite a label

This version rewrites the label of the open & close buttons using the associated *-label attributes. 

<img-enlarge open-label="View the trail photo"
  close-label="Back to the page">
  <img src="./mountains.svg" alt="A trail between green mountains.">
</img-enlarge>

Translate the labels

You can also translate every control and status message using a global JSON config. This example adds Canadian French labels to a French gallery: fr-CA supplies the Enlarge label, and fr supplies the rest. data-img-enlarge-config="french" limits these labels to images with name="french".

For a page in one language, review the single-language example. 

<script type="application/json" data-img-enlarge-config="french">
{
  "fr": {
    "open-label": "Agrandir l’image : {name}",
    "dialog-label": "Images agrandies",
    "close-label": "Fermer",
    "previous-label": "Image précédente",
    "next-label": "Image suivante",
    "loading-label": "Chargement de l’image",
    "error-label": "Impossible de charger l’image.",
    "retry-label": "Réessayer",
    "position-label": "{current} sur {total}"
  },
  "fr-CA": { "open-label": "Agrandir la photo : {name}" }
}
</script>

<div lang="fr-CA">
  <img-enlarge name="french" open-label="Agrandir le paysage">
    <img src="./mountains.svg" alt="Un sentier entre deux montagnes vertes.">
  </img-enlarge>
  <img-enlarge name="french">
    <img src="./bicycle.svg" alt="Un vélo rouge avec un panier.">
  </img-enlarge>
</div>

Galleries

Simple gallery

Put several images inside one <img-enlarge> to create a distinct gallery.

In gallery mode, arrow buttons are added and the keyboard’s Left and Right arrow keys can be used to browse. Open either photo to start there; use Close or Escape to return to its Enlarge button. 

<img-enlarge force open-label="Enlarge ride photo: {name}">
  <figure>
    <img src="./bicycle.svg" width="192" height="108"
      alt="A red bicycle with a basket beside a pale stone path.">
    <figcaption>The bicycle, ready for the ride.</figcaption>
  </figure>
  <figure>
    <picture>
      <source media="(min-width: 40rem)" srcset="./mountains-large.svg">
      <img src="./mountains.svg" width="192" height="96"
        alt="A trail between two green mountains beneath a golden sun.">
    </picture>
    <figcaption>The trail at the end of the afternoon.</figcaption>
  </figure>
</img-enlarge>

Named gallery

Give separate <img-enlarge> elements the same name to connect their images. These bicycle photos share name="city-bike". Open a detail photo to browse all three, even if the larger bicycle image has no Enlarge button. A wrapper without a name stays in its own gallery. 

<div class="product-gallery">
  <img-enlarge name="city-bike" caption="The city bicycle.">
    <a href="./bicycle.svg">
      <img src="./bicycle.svg" alt="A red city bicycle with a basket.">
    </a>
  </img-enlarge>
  <img-enlarge name="city-bike" caption="The front basket.">
    <img src="./bicycle-basket.svg" alt="A woven basket above the front wheel.">
  </img-enlarge>
  <img-enlarge name="city-bike" caption="The rear wheel.">
    <img src="./bicycle-wheel.svg" alt="The bicycle’s rear wheel and frame.">
  </img-enlarge>
</div>

Everyday city bicycle

A step-through frame, a front basket, and room for an afternoon’s errands.

HTML navigation buttons

The component normally uses CSS-generated navigation buttons when they’re supported, with JavaScript-injected HTML buttons as a fallback. Set controls="buttons" to force the HTML buttons in every browser. 

<img-enlarge name="details" controls="buttons">
  <img src="./bicycle.svg" alt="A red bicycle with a basket.">
</img-enlarge>
<img-enlarge name="details" controls="buttons">
  <img src="./bicycle-basket.svg" alt="A woven basket above the front wheel.">
</img-enlarge>

Styling

Use a class on <img-enlarge> to alter that viewer’s look and feel. The README lists the styling hooks.

Basic styling

Use a class on the component to style one viewer. Here, the caption sits beside the image on wide screens and below it on narrow screens. 

<img-enlarge class="editorial" force
  caption="An afternoon on the mountain trail.">
  <img src="./mountains.svg" alt="A trail through green mountains.">
</img-enlarge>

<style>
.editorial {
  --img-enlarge-dialog-padding: 4rem;
  --img-enlarge-caption-gap: 1.5rem;
}
.editorial .img-enlarge-slide {
  display: grid;
  grid-template-columns: minmax(0, 3fr) minmax(0, 2fr);
  gap: 1.5rem;
  align-items: center;
  text-align: start;
}
@media (max-width: 40rem) {
  .editorial { --img-enlarge-dialog-padding: 3.5rem; }
  .editorial .img-enlarge-slide { grid-template-columns: minmax(0, 1fr); }
}
</style>

Gallery styling

This gallery fades the overlay in and out and animates the change between images. The controls sit plainly against the canvas, with native keyboard focus indicators. Motion is disabled when you prefer reduced motion. 

<img-enlarge class="animated-gallery gallery-thumbnails" force>
  <figure>
    <img src="./bicycle.svg" alt="A red bicycle with a basket.">
    <figcaption>The bicycle, ready for a ride.</figcaption>
  </figure>
  <figure>
    <img src="./bicycle-basket.svg" alt="A woven basket above the front wheel.">
    <figcaption>The basket has room for a small bag.</figcaption>
  </figure>
</img-enlarge>

<style>
.gallery-thumbnails {

  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;

    display 220ms allow-discrete, overlay 220ms allow-discrete;

.animated-gallery .img-enlarge-dialog[open] {
  opacity: 1;
  transform: translateY(0);
}
.animated-gallery .img-enlarge-dialog::backdrop {
  opacity: 0;
  transition: opacity 220ms ease, display 220ms allow-discrete,
    overlay 220ms allow-discrete;
}
.animated-gallery .img-enlarge-dialog[open]::backdrop {
  opacity: 1;
}
@supports not (overlay: auto) {
  .animated-gallery .img-enlarge-dialog {
    display: grid;
    z-index: 1;
    box-shadow: 0 0 0 100vmax rgb(0 0 0 / 75%);
  }
  .animated-gallery .img-enlarge-dialog::backdrop {
    background: transparent;
  }
}
@starting-style {
  .animated-gallery .img-enlarge-dialog[open] {
    opacity: 0;
    transform: translateY(0.75rem);
  }

    opacity: 0;
  }

.animated-gallery .img-enlarge-track {

Hide disabled navigation arrows

Set --disabled-button-visibility: hidden to hide the unavailable arrow at either end of the collection. 

<img-enlarge class="hide-disabled" name="quiet-arrows">
  <img src="./mountains.svg" alt="A trail between green mountains.">
</img-enlarge>
<img-enlarge class="hide-disabled" name="quiet-arrows">
  <img src="./bicycle.svg" alt="A red bicycle with a basket.">
</img-enlarge>

<style>
.hide-disabled {
  --disabled-button-visibility: hidden;
}
</style>
