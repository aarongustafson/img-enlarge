Définir les libellés une seule fois

Une page dans une seule langue peut utiliser un objet simple, sans codes de langue. Le document indique sa langue avec <html lang="fr">. Chaque image du groupe utilise les mêmes libellés, sans attributs de traduction répétés. Sans JavaScript, les images et leurs liens restent disponibles. 

<script type="application/json" data-img-enlarge-config>
{
  "open-label": "Agrandir l’image",
  "dialog-label": "Images agrandies",
  "close-label": "Fermer",
  "previous-label": "Image précédente",
  "next-label": "Image suivante",
  "loading-label": "Chargement de l’image",
  "error-label": "Impossible de charger l’image.",
  "retry-label": "Réessayer",
  "position-label": "{current} sur {total}"
}
</script>
